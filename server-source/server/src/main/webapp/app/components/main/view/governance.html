Database backups

Backups are full PostgreSQL dumps stored on the server (/opt/hmdm/backups, outside the application container's own filesystem). Restoring automatically snapshots the current state first, so a bad restore is itself recoverable.

The backup API is not available on this server. rest/private/backup/list answered 404, so this server build cannot create, list, download or restore database backups. Configuration export and import above still work.
