Backups e importação

Configurações são importadas por atualização e inclusão, preservando outros cadastros. Dados e backup completo restauram o banco inteiro. Toda restauração cria antes uma cópia de segurança completa.

Os backups são cópias completas do PostgreSQL guardadas no servidor (/opt/hmdm/backups, fora do sistema de arquivos do container). Toda restauração tira antes uma cópia do estado atual, então uma restauração errada também pode ser desfeita.

A API de backup não está disponível neste servidor. rest/private/backup/list respondeu 404: este servidor não consegue criar, listar, baixar nem restaurar backups do banco. A exportação e importação de configuração acima continuam funcionando.
